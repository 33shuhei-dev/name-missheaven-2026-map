# 出場者名の回収：Phase 3b 保存済み検索結果の全国再解析（2026-10-06）

新たな検索はしていない。Phase 3b の保存済み検索結果（log_pref.json・log_queue.json）だけを使った。神奈川県は実証済み（kanagawa_entrant_pilot.md）のため対象外。

## 手順
1. `national_candidates.py`：全検索結果（重複URL除く）を既存店舗（Phase 3b の店舗キー・照合記録・Phase 3 の公開URL）に対応付け、
   店舗ごとに複数ページで繰り返される文（店舗共通の見出し・バナー）を除いたうえで、ミスヘブンと出場の語がある結果を候補にした（982件）。
2. 出場の表明（出場・エントリー・ノミネート・参加・挑戦・意気込み等）がミスヘブンの近くにあるもの、他サイトは既存の店名を含むものに絞った（540件。うち店舗がデータにない78件は対象外）。
3. 残り462件を4つに分けて人手（レビュー担当）で判定。基準は data/entrant-updates.ts と同じ（人物名・2026年の出場・所属店舗・根拠）。
4. `merge_entrants.py`：根拠の引用が抜粋と一字一句一致すること、名前が抜粋にあること、店舗の一致を機械的に確認。境界例を見直して4件を除外。
   同じ店舗・同じ名前を統合し、既存の出場者（Phase 1・記録済み）と重なる9人を除外。
5. `build_nationwide.py`：data/entrants/nationwide-reanalysis-2026-10-06.json を出力。「その他のページ」だけが根拠の1人は記録しない。
