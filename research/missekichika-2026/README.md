```bash
cd research/missekichika-2026
python3 -I official_list.py /tmp/off2026.json /tmp/offcache          # 「一覧ページ 54/54 公開」になるまで待つ
python3 -I reconcile.py /tmp/off2026.json missekichika2026_entrants_YYYY-MM-DD.xlsx YYYY-MM-DD
```
照合結果シートの見方:
- 一致: 候補が公式一覧にいる
- 不一致: 根拠は開けたが、公式一覧にいない
- URL死活: 根拠かプロフィールが開けなかった（不一致とは分ける）
- 公式のみ: 公式一覧にだけいる人
