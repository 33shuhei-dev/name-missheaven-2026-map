### 判定ルール
- 数える: 本人の出場表明（出場・エントリー・参加・ノミネート・出ます 等）、店舗・店舗グループが名前を挙げた告知
- 数えない（要確認）: 投票・マイガール登録の依頼だけ、ファンの投稿、既存の人と同一人物の可能性がある X のみの投稿
- 前年以前の日記は日記IDで除外（ID 419,000,000 未満 ≒ 2026-09-28 より前。2025年11月は約3.67億、2023年は約2.55億）
- 同一人物: 駅ちかの女の子ID → Xアカウント → 都道府県＋源氏名＋店名 の順でまとめる。同じグループの別店舗ページに同じ文面で載っている人（HIGH CLASS・ZEUS・Mieria・Aillis・VIXIE 等）は1人
- 店舗告知の名前は、その店舗の在籍一覧で源氏名を照合してプロフィールURLを付けた（一意に決まらないものは要確認）

## 再開手順（2026-11-11（水）12:00以降）
```bash
cd research/missekichika-2026

```

## 調べられなかった範囲
- 日記の一括調査は2025年の参加店舗が中心。2026年に新しく参加した店舗の多くは、エリア別一覧の最新日記タイトルでしか見ていない
- 日記の多い店は最新4ページ（およそ数日分）だけ。それより前の告知は拾えていない可能性がある
- 日記を書かない出場者、X だけで告知する出場者は拾いにくい（X は Yahoo!リアルタイム検索に出た117投稿のみ）
- 鳥取・島根・和歌山などは該当なし
